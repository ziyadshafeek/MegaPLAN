## Fixed on this branch

- Changed all 28 dispatch cases to literal `import()` paths. `@vercel/nft` now traces all 26 `lib/api` handlers, plus the shared helpers. The bundle test is in `tests/vercel-bundle.mjs`.
- `split-pdf` was not a Node handler at all; added a multipart Node-to-Web adapter and tested a generated 2-page PDF returns a ZIP with two PDF parts.
- Hosted planner validated using a mocked upstream response, not a real paid model request. Generated preview HTML is executed in a jsdom DOM with passing and failing declarative checks; this does not replicate Chromium iframe isolation. Model key still needs to exist on Vercel.
- Replaced the Wiki Agent preview's inaccessible `iframe.contentDocument` check with test results posted from inside the opaque-origin iframe using a random nonce and source check. Corrected the literal closing `</script>`; removed dynamic `Function` evaluation for numeric expressions. Publish is disabled until preview checks pass.
- The public write endpoints `/api/agent-publish` and `/api/agent-dispatch` now require `AGENT_WRITE_TOKEN` on the server and a matching operator-only header. Client-provided test proof is **not** independently verifiable by the server; it is an additional UI guard, not authentication.
- Fixed GitHub Actions browser regression test to inspect the sandboxed iframe, and served its imported `/js` directory in the test fixture.
- Fixed optional `NVIDIA_AGENT_MODEL` handling in env sync and made missing Vercel token fail the workflow instead of reporting a successful skip.
- Registry: normalized 15 missing statuses and 2 obsolete processing values, marked known placeholder video/audio features as beta with accurate descriptions. The tool routing audit verifies that **585/585 titles are assigned to a runner or dedicated category engine**; this is *not* 585 functional E2E tests.
