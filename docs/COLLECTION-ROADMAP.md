# Recurring data collection: what is real, what is not

**“Music” means recording/song names and metadata only, never audio files.** Latest verified branch trial: 249 distinct MusicBrainz recording names, 4 map cells/370 overlapping place occurrences, 120 local shops, 48 unreviewed image-link candidates, and 0 authorized retailer products. The user's requested Spotify-wide inventory is different from a CC0 MusicBrainz catalog: do not claim the latter is all Spotify tracks. Trivandrum OSM music *places* are yet another independent source.

## Current branch, then default-branch operation

| Source | Implemented background job | Storage and actual scope | To reach requested completeness |

**GitHub Actions cron only runs workflows from the repository default branch.** The branch-only `collect-now.yml` push event exercises the collectors once now; recurring timers in their dedicated workflows begin *only after review/merge*. GitHub may delay scheduled jobs, upstreams can fail or rate-limit, and Git is not a suitable home for full global datasets. `/tools/data-sources-status` exposes actual counts and provenance, not promises. `auto-master` is now manual-only to avoid duplicate simultaneous collector jobs; jobs share a concurrency group.

## Similar GitHub projects investigated (use patterns, not unauthorized data)

- [metabrainz/musicbrainz-docker](https://github.com/metabrainz/musicbrainz-docker): official PostgreSQL full-dump + replication setup; a realistic large catalog path. Review code licensing separately from MusicBrainz **data** license.
- [beetbox/beets](https://github.com/beetbox/beets) (MIT): metadata tagging client using MusicBrainz; not a Spotify-wide dataset.
- [Borewit/musicbrainz-api](https://github.com/Borewit/musicbrainz-api) (MIT): API client pattern; provider rate and search limits still apply.
- [osmcode/pyosmium](https://github.com/osmcode/pyosmium) (BSD-2-Clause): OSM extract/diff processing for map scale; source data remains ODbL.
- [zivost/flipkart-affiliate-client](https://github.com/zivost/flipkart-affiliate-client) (MIT): community client for the affiliate API; verify API version/eligibility with Flipkart and obtain your own permitted credentials/rights. A code license does not license Flipkart product data.

Official source guides: [MusicBrainz JSON dumps](https://musicbrainz.org/doc/Development/JSON_Data_Dumps), [MusicBrainz rate limits](https://musicbrainz.org/doc/MusicBrainz_API/Rate_Limiting), [MetaBrainz datasets](https://metabrainz.org/datasets/postgres-dumps), [OSM planet](https://wiki.openstreetmap.org/wiki/Planet.osm), [Flipkart affiliate tools](https://affiliate.flipkart.com/tools/affiliate-tools-info). Do not clone unknown scraping bots or bypass retailer/Spotify access controls.
