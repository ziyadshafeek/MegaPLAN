# Slide style reference from user example

Target study-slide characteristics:
- Dense but readable: important content stays on the slide rather than being hidden in speaker notes.
- Strong title hierarchy and section headers.
- Compact boxed groupings for related facts.
- Short bullet phrases for exam recall, while preserving key source terminology.
- Visual anchors: simple medical diagrams/icons where they materially improve recall.
- Consistent color hierarchy, not decorative gradients.
- Clinical case vignettes can be highlighted separately.
- Tables/flows should be used for mechanisms and pathways.
- Treatment protocols can use stepwise visual blocks and warning callouts.
- Each split section should be explicitly labelled Part X of N.

This is a design brief based on the uploaded user examples, not a copy of their source content.
