# FreeToolForge AI Worker

Optional heavy processing backend for OCR/transcription/denoise. A free personal Hugging Face account in good standing can host up to 2 ZeroGPU Spaces; the free tier currently includes 5 minutes/day of ZeroGPU quota. Use this only as an on-demand backend, not as the site's only availability layer.

Never put secrets in this Space. Use environment variables/secrets and validate model licenses before commercial use.
