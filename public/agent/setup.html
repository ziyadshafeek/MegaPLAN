Secure runner setup

This page is for operators. It stores the hosted writing-assistant credential as a GitHub Actions secret (source of truth). Vercel does not inherit GitHub secrets. After saving here, run the GitHub workflow “Sync hosted AI env to Vercel” (needs GitHub secret VERCEL_TOKEN) so instant website Build works. Customers never see this page unless you send them here. The value is encrypted with GitHub’s repository public key before it leaves MegaPLAN.
